# Practice 09: Game Development with Pygame

Install dependencies with `pip install -r requirements.txt`.

Run each application separately from its directory:

- `cd mickeys_clock && python main.py`
- `cd music_player && python main.py`
- `cd moving_ball && python main.py`

For the music player, add audio files to `music_player/music/` or `music_player/music/sample_tracks/`.
