# TSIS 2 - Paint Application

Install and run:

```bash
pip install -r requirements.txt
python paint.py
```

Tools: pencil, line, rectangle, circle, square, right triangle, equilateral triangle, rhombus, flood fill, text, eraser, and color picker.

Use 1, 2, 3 to change brush size (2, 5, 10 px). Ctrl+S saves a timestamped PNG in the saves folder. Enter confirms text and Escape cancels it.
