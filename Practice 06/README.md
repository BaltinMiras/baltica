# Practice 6: File Handling and Built-in Functions

Run any script with `python script.py`. Scripts create their demo files next to themselves.

- `file_handling/` - write (w, a, x), read, copy, backup, safe delete
- `directory_management/` - nested dirs, listing, find by extension, move/copy
- `builtin_functions/` - map, filter, reduce, enumerate, zip, type conversion
- `combined_exercises/` - the 8 exercises with files and directories (ex1-ex8)
